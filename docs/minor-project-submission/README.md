## Rendering Mermaid Diagrams

All diagrams in `PROJECT_CURRENT_STATE_AUDIT.md` are Mermaid source code.

**Option A — Online:** Copy a diagram block into [https://mermaid.live](https://mermaid.live) → export PNG → save to the correct folder.

**Option B — CLI:**
```bash
npm install -g @mermaid-js/mermaid-cli
mmdc -i diagram.mmd -o diagram.png
```

**Option C — VS Code:** Install the Mermaid Preview extension, open the `.md` file, preview rendered diagrams.
